# 04. 페이지 제어와 사후 검증

페이지 나눔, 페이지 번호, PDF 변환을 통한 시각 검증, 그리고 글자크기 사후 보정 패턴.

---

## 페이지 나눔

```python
hwp.HAction.Run("BreakPage")
```

장(章)과 장 사이에 호출. 표지 → 목차 → 본문 1장 → ... 사이에 각각 한 번씩.

---

## 페이지 번호 — `- N -` 형식

본문 표준은 하단 중앙에 `- 1 -`, `- 2 -` 식. 표지 제외.

```python
hwp.HAction.GetDefault("PageNumPos", hwp.HParameterSet.HPageNumPos.HSet)
pn = hwp.HParameterSet.HPageNumPos
pn.Pos = 8           # 8 = 중앙 하단 (1=좌상단, 2=중상단, ..., 7=좌하단, 8=중하단, 9=우하단)
pn.NumberFormat = 0  # 0 = 1,2,3 (1=I,II,III, 2=i,ii,iii, ...)
pn.SideChar = 1      # 1 = 양옆에 - - 추가
hwp.HAction.Execute("PageNumPos", pn.HSet)
```

**`SideChar = 1`이 핵심** — 안 넣으면 그냥 `1`만 찍힘.

### 표지 페이지 번호 제외

위 코드는 모든 페이지에 번호를 넣는다. 표지(첫 페이지)는 번호를 빼려면:
- 표지를 별도 섹션으로 분리하거나
- 작성 후 표지 페이지의 페이지번호 컨트롤을 수동 삭제

학교 과제 수준에선 모든 페이지에 번호 찍혀도 무방. 까다롭게 빼야 한다면 섹션 분리 패턴이 정공법.

---

## PDF 변환 — 시각 검증 필수

작성 후 **반드시** PDF로 변환해서 눈으로 확인. .hwp만 보고 끝내지 말 것 — 그림 크기, 표 정렬, 글자 크기 잔류 등이 PDF에서야 명확히 보임.

```python
PDF = OUT_HWP.replace(".hwp", ".pdf")
hwp.HAction.GetDefault("FileSaveAsPdf", hwp.HParameterSet.HFileOpenSave.HSet)
hwp.HParameterSet.HFileOpenSave.filename = PDF
hwp.HParameterSet.HFileOpenSave.Format = "PDF"
hwp.HAction.Execute("FileSaveAsPdf", hwp.HParameterSet.HFileOpenSave.HSet)
```

스크립트 끝에 `SaveAs` 다음에 바로 붙여 매번 자동 변환되도록 하는 게 권장.

print("Pages:", hwp.PageCount)

## 사후 글자크기 보정 — 잔류 글자 정리

[01-글자-렌더링.md](./01-글자-렌더링.md) 정답대로 매 write마다 `set_char_shape`을 부르면 사후 보정은 필요 없다. 하지만 기존 .hwp를 열어 일괄 점검하고 싶을 때 패턴:

```python
import win32com.client as win32

PATH = r"C:\path\to\file.hwp"

hwp = win32.gencache.EnsureDispatch("HWPFrame.HwpObject")
try:
    hwp.RegisterModule("FilePathCheckDLL", "FilePathCheckerModule")
except Exception:
    pass
hwp.XHwpWindows.Item(0).Visible = False
hwp.SetMessageBoxMode(0x2FF1)
hwp.Open(PATH, "HWP", "")

# 표지 건너뛰고 본문부터
hwp.HAction.Run("MoveDocBegin")
hwp.HAction.Run("MovePageDown")  # 2페이지로
hwp.HAction.Run("MoveLineStart")

problems = []
para_no = 0
while True:
    hwp.HAction.Run("MoveLineStart")
    hwp.HAction.Run("MoveSelLineEnd")
    hwp.HAction.GetDefault("CharShape", hwp.HParameterSet.HCharShape.HSet)
    h = hwp.HParameterSet.HCharShape.Height
    hwp.HAction.Run("Cancel")

    if h != 0 and h != 1200:  # 12pt 아닌 단락 발견
        problems.append((para_no, h))
        # 강제로 12pt로 변환
        hwp.HAction.Run("MoveLineStart")
        hwp.HAction.Run("MoveSelLineEnd")
        hwp.HAction.GetDefault("CharShape", hwp.HParameterSet.HCharShape.HSet)
        hwp.HParameterSet.HCharShape.Height = 1200
        hwp.HAction.Execute("CharShape", hwp.HParameterSet.HCharShape.HSet)
        hwp.HAction.Run("Cancel")

    para_no += 1
    moved = hwp.HAction.Run("MoveDown")
    if not moved or para_no > 1500:
        break

print(f"Fixed {len(problems)} paragraphs:", problems[:30])
hwp.Save()
hwp.Quit()
```

**권장하지 않음 (사후 보정의 한계)**:
- 단락 단위 검사라 표·그림 안의 글자는 못 잡음
- `Height` 외 다른 속성(폰트·서브셋)은 손대지 못함
- 정확한 문단 경계 인식이 환경따라 어긋남

→ **처음부터 helper로 매번 `set_char_shape` 부르는 게 정답.** 사후 보정은 비상용.

## 사후 점검 체크리스트

저장 후 PDF로 변환해 다음을 시각 확인:

- [ ] 표지가 한 페이지에 들어가는가
- [ ] 본문 모든 단락이 12pt로 일관되는가
- [ ] 그림이 130mm 이하 높이로 본문 안에 들어가는가
- [ ] 표가 본문 폭(150mm) 안에 들어가고 칼럼이 정렬됐는가
- [ ] 표 다음 본문이 셀 안에 들어가지 않고 별도 단락으로 나오는가
- [ ] 페이지 번호 `- 1 -`, `- 2 -` 형식으로 하단 중앙에 찍혔는가
- [ ] 총 페이지 수가 목표 분량에 맞는가 (`hwp.PageCount`)
- [ ] 한글·영문·숫자가 모두 보이는가 (특정 언어 서브셋 누락 없는가)

---

## 자주 막히는 지점

- **`BreakPage` 후 첫 줄에 빈 단락이 남음**: 정상 — `BreakPage` 자체가 단락 분리. 추가 `br()` 호출하지 말 것.
- **PDF 변환 후 글자가 깨져 보임**: 시스템에 함초롬바탕 폰트가 없을 때. Hancom Office 정상 설치 확인.
- **`hwp.PageCount`가 0**: 문서 열기/생성 실패. 그 위 코드부터 다시 점검.
- **PDF 변환 시 메모리 오류**: 그림이 너무 많거나 크면 발생. [02-이미지-크기제어.md](./02-이미지-크기제어.md)대로 130mm 캡 적용 확인.
