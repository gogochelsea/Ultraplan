# 03. 표 안전생성 ★

표는 HWP COM에서 가장 까다로운 영역. 함정이 3개 있고, 각각 다른 방식으로 깨진다.

---

## 함정 3가지

### 함정 1: 표를 텍스트로 흉내내기

**증상**: 표가 정렬 안 된 글자 나열로 보임.

```python
# ❌ 나쁜 예 — 절대 이렇게 하지 말 것
write_para(
    "  당사 : λ 0.022 W/m·K, pHRR 220, 흡습률 1.2%, 가격 200\n"
    "  K사  : λ 0.034 W/m·K, pHRR 80,  흡습률 0.5%, 가격 130\n"
    "  B사  : λ 0.020 W/m·K, pHRR 280, 흡습률 2.5%, 가격 180"
)
```

뷰어에서 보면 줄바꿈은 되지만 칼럼이 안 맞아 표가 아니라 글자 더미로 보임. **반드시 진짜 `TableCreate`를 써야 함.**

### 함정 2: 두 번째 표부터 COM 오류

**증상**: 첫 표는 잘 만들어지는데 두 번째 `TableCreate` 호출 시 `pywintypes.com_error`.

**원인**: `hwp.HParameterSet.HTableCreation`은 **싱글턴**이다. 두 번째 호출 시 첫 호출의 `ColWidth`/`RowHeight` 배열이 잔류하면서 충돌.

**정답**: 표마다 `hwp.CreateAction("TableCreate")`로 새 액션을 만들고 `act.CreateSet()`으로 새 파라미터셋을 만든다.

```python
# ❌ 나쁜 예 — 두 번째부터 깨짐
hwp.HAction.GetDefault("TableCreate", hwp.HParameterSet.HTableCreation.HSet)
tc = hwp.HParameterSet.HTableCreation
tc.Rows = 3; tc.Cols = 3
# ...
hwp.HAction.Execute("TableCreate", tc.HSet)

# ✅ 정답 — 매번 새 액션·새 파라미터셋
act = hwp.CreateAction("TableCreate")
pset = act.CreateSet()
act.GetDefault(pset)
pset.SetItem("Rows", 3)
pset.SetItem("Cols", 3)
# ...
act.Execute(pset)
```

### 함정 3: 표 다음 글자가 셀 안에 들어감

**증상**: 표 만든 후 본문 텍스트가 표의 마지막 셀 안에 추가됨.

**원인**: `TableCreate` 후 커서는 첫 번째 셀 안에 들어간다. 셀 채우기가 끝나도 커서는 마지막 셀 안에 머문다. 그 상태로 `insert_text`를 부르면 셀 내용이 됨.

**정답**: 표 만들기 직전에 `GetPos()`로 부모 단락 위치를 저장 → 표 채우기 후 `SetPos()`로 복귀 → `MoveLineEnd` → `BreakPara`로 표 다음 줄로 빠져나옴.

```python
saved_pos = hwp.GetPos()  # 표 만들기 직전 위치
# ... TableCreate, 셀 채우기 ...
hwp.SetPos(saved_pos[0], saved_pos[1], saved_pos[2])
hwp.HAction.Run("MoveLineEnd")
hwp.HAction.Run("BreakPara")
```

## 정답 — `make_table` 정형 패턴 (그대로 복붙)

```python
def make_table(headers, rows, col_widths_mm, body_align="center", row_h_mm=12):
    """실제 HWP 표 생성. 헤더 1행 + 본문 N행.

    핵심 함정 회피:
    - 매 호출마다 hwp.CreateAction/CreateSet — 싱글턴 재사용 시 2번째부터 COM 오류
    - HeightType=0 — 행 높이 내용 맞춤 (자동 확장)
    - 표 빠져나오기는 SetPos(부모 단락) → MoveLineEnd → BreakPara
    """
    cols = len(headers)
    nrows = len(rows) + 1
    total_w = sum(col_widths_mm)

    set_para_shape(align="center")
    set_char_shape(size_pt=10)

    saved_pos = hwp.GetPos()  # ★ 표 만들기 전 부모 단락 위치 저장

    # ★ 매 호출마다 새 액션·새 파라미터셋
    act = hwp.CreateAction("TableCreate")
    pset = act.CreateSet()
    act.GetDefault(pset)
    pset.SetItem("Rows", nrows)
    pset.SetItem("Cols", cols)
    pset.SetItem("WidthType", 2)         # 2 = 절대값(mm)
    pset.SetItem("HeightType", 0)        # 0 = 자동(내용에 맞춤)
    pset.SetItem("WidthValue",  hwp.MiliToHwpUnit(total_w))
    pset.SetItem("HeightValue", hwp.MiliToHwpUnit(row_h_mm * nrows))
    arr_w = pset.CreateItemArray("ColWidth", cols)
    for i, w in enumerate(col_widths_mm):
        arr_w.SetItem(i, hwp.MiliToHwpUnit(w))
    arr_h = pset.CreateItemArray("RowHeight", nrows)
    for i in range(nrows):
        arr_h.SetItem(i, hwp.MiliToHwpUnit(row_h_mm))
    act.Execute(pset)

    # 셀 채우기 (insert_text → 마지막 셀 아니면 TableRightCell)
    all_data = [headers] + rows
    for r, row in enumerate(all_data):
        for c, val in enumerate(row):
            set_char_shape(size_pt=10, bold=(r == 0))
            set_para_shape(align=("center" if r == 0 else body_align), line_space=150)
            insert_text(str(val))
            if not (r == nrows - 1 and c == cols - 1):
                hwp.HAction.Run("TableRightCell")

    # ★ 표 빠져나오기 — 저장한 부모 단락 위치로 복귀 후 줄끝 이동, 줄바꿈
    hwp.SetPos(saved_pos[0], saved_pos[1], saved_pos[2])
    hwp.HAction.Run("MoveLineEnd")
    set_char_shape(size_pt=12, bold=False)  # 본문 기본값 복귀
    set_para_shape(align="left")
    br()
```

## 표 파라미터 레퍼런스

| 키 | 의미 | 권장값 |
|---|---|---|
| `Rows` | 총 행 수 (헤더 포함) | `len(rows)+1` |
| `Cols` | 칼럼 수 | `len(headers)` |
| `WidthType` | 0=원본,1=비율,2=절대값,3=종이맞춤 | **`2`** |
| `HeightType` | 0=자동,1=고정 | **`0`** ★ |
| `WidthValue` | 표 전체 폭 (HWP unit) | `MiliToHwpUnit(총폭mm)` |
| `HeightValue` | 표 전체 높이 (HWP unit) | `MiliToHwpUnit(rowH × nrows)` |
| `ColWidth[i]` | i번 칼럼 폭 | `MiliToHwpUnit(col_widths_mm[i])` |
| `RowHeight[i]` | i번 행 높이 | `MiliToHwpUnit(row_h_mm)` |

`HeightType=0` (자동)이 핵심: 셀 내용이 길면 행이 자동 확장되어 잘리지 않음. `1`(고정)로 하면 긴 셀 내용이 잘려 안 보임.

---

## 칼럼 폭 가이드 (A4 기준)

A4 기본 본문 폭은 약 **150mm**. `col_widths_mm` 합이 150을 넘으면 표가 본문 영역을 벗어남.

권장 분배 예시:

| 표 종류 | 칼럼 수 | 분배 (mm) | 합계 |
|---|---|---|---|
| 시장규모 (구분/정의/규모/출처) | 4 | 20+55+30+45 | 150 |
| SWOT (구분/내용) | 2 | 28+122 | 150 |
| 로드맵 (연차/활동/capacity) | 3 | 25+95+30 | 150 |
| 손익 (구분/3개년) | 4 | 35+32+32+32 | 131 |
| 인력 (연차/4부서/합계) | 5 | 28+28+28+36+25 | 145 |

## 셀 채우기 규칙

- **헤더 행**(r=0): `bold=True`, `align=center`, 10pt
- **본문 행**(r≥1): `bold=False`, `align=left` 또는 `center` 옵션, 10pt
- **숫자 셀**: 천단위 콤마 직접 박을 것 (`"1,500"`) — 자동 포맷 없음
- **긴 텍스트 셀**: `HeightType=0`이면 자동 줄바꿈됨. 직접 `\n` 넣지 말 것

---

## 자주 막히는 지점

- **`MiliToHwpUnit`을 까먹고 mm 숫자를 그대로 넘김**: 표가 1mm짜리로 만들어짐. 무조건 환산 필수.
- **`TableRightCell`을 마지막 셀에서도 호출**: 표 밖으로 나가버려서 다음 채우기가 본문에 들어감. 마지막 셀 체크 필수.
- **`saved_pos`를 표 채우기 시작 후에 저장**: 이미 셀 안 위치라 빠져나오기 실패. 반드시 `TableCreate` 직전에 저장.
- **`set_char_shape` 안 부르고 셀 채움**: 이전 단락 폰트 잔류. 매 셀마다 부르는 게 안전.
- **표 안에서 그림 삽입**: 가능하지만 셀 크기와 그림 크기 충돌. 표·그림은 분리해서 사용 권장.
