# 02. 이미지 크기 제어 ★

`InsertPicture`만 호출하면 그림이 원본 픽셀 크기로 들어가서 한 페이지를 통째로 차지하거나 잘린다. **삽입 후 컨트롤 크기를 강제로 다시 세팅**해야 한다.

---

## 증상

- 그림 한 장이 본문 페이지를 통째로 덮음
- 그림이 페이지 하단을 넘어 다음 페이지로 잘려 들어감
- `sizeoption=0`으로 넣었더니 너무 큼, `sizeoption=2`로 넣었더니 모양이 이상함

---

## 원인

`hwp.InsertPicture(path, Embedded, sizeoption, ...)` 의 `sizeoption`:

| 값 | 의미 | 문제점 |
|---|---|---|
| `0` | 원본 크기 | 픽셀 그대로 → 거의 항상 너무 큼 |
| `1` | 종이에 맞춤 | 페이지 폭 가득 — 본문 흐름 깨짐 |
| `2` | 셀에 맞춤 | 셀 안일 때만 의미 있음 |

→ 위 옵션 중 무엇을 골라도 **mm 단위 정확한 크기**로는 못 맞춘다. 정답은: 일단 삽입한 뒤 **컨트롤 객체의 Width/Height 속성을 직접 다시 세팅**하는 것.

---

## 정답 — 4단계

### Step 1. PIL로 원본 비율 계산

```python
from PIL import Image
with Image.open(path) as im:
    iw, ih = im.size
aspect = ih / iw
```

PIL이 없으면 `aspect = 0.7` 기본값 fallback (대부분의 사진 비율).

### Step 2. mm 단위 폭·높이 결정 (130mm 캡)

```python
width_mm = 120          # 기본 폭
if height_mm is None:
    height_mm = width_mm * aspect
    if height_mm > 130:  # ★ 한 페이지 안에 안 들어가는 그림 방지
        height_mm = 130
        width_mm = height_mm / aspect
```

**130mm 캡이 핵심.** A4 본문 영역 높이는 약 247mm지만, 페이지에 텍스트와 함께 들어가야 하므로 그림 1장 높이를 130mm로 제한해야 흐름이 깨지지 않는다.

### Step 3. mm → HWP 단위 환산

```python
HWPMM = 283.464567  # 1 mm = 283.46 HWP unit
w_unit = int(width_mm * HWPMM)
h_unit = int(height_mm * HWPMM)
```

**상수 `283.464567`**은 외울 것 — HWP 내부 단위(7200 dpi 기준 1/100 pt)에서 1mm가 정확히 이 값이다. `hwp.MiliToHwpUnit(width_mm)`을 써도 같은 결과.

### Step 4. InsertPicture 후 HeadCtrl로 컨트롤 찾아 크기 강제

```python
hwp.InsertPicture(path, True, 2, False)  # 일단 삽입

# HeadCtrl 체인 순회 — 마지막 'gso'(general shape object)가 방금 넣은 그림
last = hwp.HeadCtrl
target = None
while last:
    if last.CtrlID == "gso":
        target = last
    last = last.Next

if target:
    prop = target.Properties
    prop.SetItem("Width",  w_unit)
    prop.SetItem("Height", h_unit)
    target.Properties = prop  # ★ 다시 할당해야 적용됨
```

`HeadCtrl` 체인은 문서 안의 모든 컨트롤(표·그림·도형 등)을 순회. `CtrlID == "gso"` 가 그림. 마지막 것이 방금 삽입한 것이라는 보장은 100%는 아니지만, `InsertPicture` 직후라면 사실상 신뢰 가능.

## 전체 helper (그대로 복붙)

```python
def insert_picture(path, width_mm=120, height_mm=None, caption=None):
    """이미지 삽입 — width_mm 기준, 비율 유지, 130mm 높이 캡, 캡션 옵션."""
    if not os.path.exists(path):
        print(f"[WARN] image not found: {path}")
        return

    # 비율 계산
    try:
        from PIL import Image
        with Image.open(path) as im:
            iw, ih = im.size
        aspect = ih / iw
    except Exception:
        aspect = 0.7

    if height_mm is None:
        height_mm = width_mm * aspect
        if height_mm > 130:
            height_mm = 130
            width_mm = height_mm / aspect

    set_para_shape(align="center")
    set_char_shape(size_pt=12)

    HWPMM = 283.464567
    w_unit = int(width_mm * HWPMM)
    h_unit = int(height_mm * HWPMM)

    try:
        hwp.InsertPicture(path, True, 2, False)
    except Exception:
        try:
            hwp.InsertPicture(path, True, 0, False)
        except Exception as e:
            print("InsertPicture err:", e)

    # 마지막 gso 컨트롤 찾아 크기 강제
    try:
        last = hwp.HeadCtrl
        target = None
        while last:
            if last.CtrlID == "gso":
                target = last
            last = last.Next
        if target:
            prop = target.Properties
            prop.SetItem("Width",  w_unit)
            prop.SetItem("Height", h_unit)
            target.Properties = prop
    except Exception as e:
        print("Resize err:", e)

    br()  # 그림 다음 줄로

    if caption:
        set_char_shape(size_pt=11, bold=False)
        set_para_shape(align="center")
        insert_text(caption)
        br()

    set_para_shape(align="left")  # ★ 다음 본문 위해 정렬 복귀
```

## 캡션 패턴

그림 아래 한 줄, 가운데 정렬, 11pt:

```
<그림 N> 설명 텍스트
```

예: `<그림 3> 외벽 마감재 실대형 모형 화재시험기 (KS F 8414)`

번호는 수동으로 매김 — 자동 캡션 번호는 HWP 캡션 기능이 따로 있지만 COM에서 다루기 까다롭다. 그냥 본문에 텍스트로 박는 게 안전.

---

## 자주 막히는 지점

- **`Properties = prop` 재할당 빠뜨림**: `SetItem`만으로는 안 적용됨. 반드시 다시 할당.
- **`HeadCtrl`이 None**: 문서가 비어있거나 삽입이 silently 실패한 경우. `InsertPicture` 반환값 체크.
- **`gso` 컨트롤이 그림이 아니라 도형(직사각형 등)일 수 있음**: 그림만 따로 식별하려면 `CtrlID=="gso"` AND 추가로 형식 확인 필요. 단순 케이스에선 `gso`만 보면 충분.
- **bmp 파일 삽입 실패**: HWP가 BMP를 거절하는 경우 있음. PNG로 변환해서 사용 (`Image.open(bmp).save(png)`).
- **그림 다음 본문 정렬이 가운데 정렬로 남음**: helper 끝에서 `set_para_shape(align="left")` 호출로 복귀.
